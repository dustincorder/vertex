# Vertex

Vertex — самостоятельное серверное ядро для **Minecraft Java Edition 26.3**, написанное на Go с нуля. Первые целевые платформы — Android/Termux и Raspberry Pi 3B. Bedrock Edition не поддерживается.

## Играбельный прототип

Текущая версия принимает подключения Java 26.3 в offline-режиме, завершает Login и Configuration, запускает состояние Play и выдаёт плоский мир с равнинами. Игрок появляется на поверхности; при перемещении Vertex подгружает чанки в радиусе двух чанков и выгружает те, что вышли за радиус. Мир использует повторно применяемый шаблон и пока не сохраняется на диск.

Это ранний игровой MVP, а не полный survival-сервер: ломание и установка блоков, инвентарь, существа, чат, видимость других игроков, сохранение мира и проверка аккаунта Microsoft пока не реализованы. В offline-режиме любой клиент может занять любое имя игрока. Используйте сервер только в доверенной локальной сети и не открывайте его в публичный интернет.

## Запуск

Сборка непосредственно в Termux:

```sh
pkg install golang
go build -trimpath -ldflags='-s -w' -o vertex .
./vertex -listen :25565
```

Сборка для 64-битного Android или Raspberry Pi OS:

```sh
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o vertex .
```

Сборка для 32-битной Raspberry Pi OS на Pi 3B:

```sh
GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o vertex .
```

Запустите `./vertex -listen :25565`. Друзья в той же Wi-Fi сети подключаются к локальному IP телефона или Raspberry Pi и порту `25565`, используя Minecraft Java Edition 26.3. Телефон должен оставаться включённым и подключённым к Wi-Fi.

## Проверка

Сериализация чанка проверяется декодированием и сравнением с захватом vanilla 26.3. Клиент протокола 777 завершил вход, получил стартовые 25 чанков и при переходе через границы получил новые чанки; вышедшие из окна обзора чанки были удалены. Успешно собраны Windows, Linux ARM64 и Linux ARMv7.

## Структура

- `internal/protocol` — ограниченный Minecraft TCP-фрейминг, login/configuration, пакеты Play и сериализация плоских чанков 26.3.
- `internal/protocol/data/v777` — зафиксированные тела vanilla configuration-пакетов; рядом указаны источник и лицензия.
- `internal/world` — модель плоской местности и ограниченная очередь для будущей процедурной генерации.
- `internal/server` — TCP listener и отдельная goroutine на подключение.
